# Viper → Sidewinder

Pokladna se přejmenovala a přestěhovala: https://vojtasak9.github.io/cash-desk/sidewinder/ (kód ve složce [`sidewinder/`](../sidewinder/)).

Tahle složka zůstává jen kvůli starým ikonám na ploše: stránka pošle neodeslané prodeje do tabulky,
zkopíruje data zařízení („Copy my data“) a nová ikona Sidewinder je vloží („Paste from Viper“).
